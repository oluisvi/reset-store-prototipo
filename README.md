# RESET STORE · Vitrine conceitual

Prévia de uma página para apresentar roupas, calçados e kits da Reset Store. O visitante pode alternar entre três estruturas de navegação: Editorial, Loja direta e Lookbook. A escolha fica salva no navegador.

## Estado desta prévia

- As imagens são fotografias de referência licenciadas via Pexels, não fotos do estoque da Reset Store.
- As peças são referências visuais. Não existem preços, estoque, tamanhos ou promessas de entrega inventados nesta página.
- Os contatos da vitrine levam ao perfil público de Instagram informado na conversa.
- A página é um protótipo estático, sem carrinho, pagamento ou integração de estoque.

## Rodar localmente

Abra index.html em um navegador ou sirva a pasta com python -m http.server 8767.
